# familiar-ai 設計方針：クレジット切れの知らせ（v0.1）

LLM の残高（クレジット）が切れたら、パジュは**専用の情動**（知らせたい）を持ち、人が来たら録音済みの声で
「〇〇のクレジットが足りなくなりました。」と伝える。課題は `課題8` の環-z。

## 1. 目的

残高が切れたことを、人が気づけるようにする。

実機 2026-09-26 08:27〜08:39、軽量LLM（Gemini）が 402「Your prepayment credits are depleted」を返し続けた（12 分で
240 回）。調停・発話前の検査・記憶の判定・感情の評価がすべて失敗し、「パジュ、30分黙ってて」は受け付けられなかった。
人からは、何が起きているのか分からなかった。

壊れ方は、どの担い手が切れたかで違う。

- **主LLM**：返事が空になり、話しかけても黙る。情動の話しかけも出ない。
- **軽量LLM**：調停が空の返事から主LLM へ倒れるので話しはするが、黙る依頼が読めず、つなぎや要約が作れない。
- **Jev**：判定ごとの倒し先へ倒れて動き続けるが、判断の質が落ちる。

どれが切れても、伝える口が LLM しかなければ、切れたことを話せない。

## 2. 見分ける

担い手（主LLM・軽量LLM・Jev）の残高切れを、1 か所（`core/credit.is_credit_exhausted`）で見分ける。

| 担い手 | 残高切れの返り方 | 確かめ |
|---|---|---|
| Gemini | 402、または「credits are depleted」「prepayment credits」 | 実物（2026-09-26） |
| Anthropic | 「credit balance is too low」（400） | 文書の上 |
| OpenAI 系（GLM・Kimi を含む） | `insufficient_quota`・「insufficient balance」 | 文書の上 |
| Jev（TypeSafe AI） | 402 | 推測 |

Gemini の `RESOURCE_EXHAUSTED` は回数制限の 429 にも使われるので、それだけでは残高切れとしない。

残高切れは一時的な失敗ではないので、やり直さない（`backends/shared._is_transient_error`）。以前は文字列に
`resource_exhausted` を含むので一時的とみなし、1 回の依頼で 3 回叩いていた。

## 3. 専用の情動

残高切れを見分けたら、担い手ごとに**知らせたい**が立つ。

- **置き場**：DB（`agent_state` の鍵 `credit_alerts`・担い手 → 切れた時刻）。再起動をまたいで残る。LLM の呼び出しの
  たびに見るので、プロセスの中に写しを持ち、変わったときだけ書く。
- **立つ・消える**：担い手の口（`stream_turn`・`complete`・`complete_with_image`）を `backends/shared.watch_credit` で
  包む。例外が外へ出れば立て（残高切れのときだけ）、出なければ（中で失敗を受け止めていなければ）消す。失敗を受け止めて
  空の返事を返す口は、受け止める箇所で `credit.note_failure` を呼ぶ。Jev は返りの状態が 402 なら立て、200 で消す。
- **担い手の名前**：`credit_name`（`anthropic`・`gemini`・`openai`・`glm`・`kimi`・`jev`）。同じ担い手が 2 つの役を
  持つこともあるので、役ではなく担い手で持つ。

## 4. 伝える

T の tick（`Tonic._maybe_tell_credit`）が、知らせたいがあり、**居る**（顔ぶれか在席・`設計方針_在席と顔ぶれ` §5）ときに
伝える。

- **伝える時**：居ない → 居る に変わるたびに伝える（本人の決定ア）。立った時点ですでに居れば、すぐ伝える。居続けている
  あいだは繰り返さない。回復したあとにまた切れたら、伝え直す。
- **門**：情動と同じにする。「黙っていて」のあいだは控え、明けたら伝える。夜も鳴らす（本人の決定ア）。
- **伝え方**：LLM も TTS も通さず、録音済みの声を鳴らす（`DIF.say_credit`・タイマーの音と同じ口・倍率は `TTS_GAIN`）。
  録音が無ければ警告を残すだけで落とさない。

## 5. 録音

文言は「〇〇のクレジットが足りなくなりました。」で、〇〇は AI の名前にする（本人の決定）。

| 担い手 | 読み | 録音 |
|---|---|---|
| Anthropic | クロード | `sounds/credit_anthropic.wav` |
| Gemini | ジェミニ | `sounds/credit_gemini.wav` |
| OpenAI | チャットジーピーティー | `sounds/credit_openai.wav` |
| GLM | ジーエルエム | `sounds/credit_glm.wav` |
| Kimi | キミ | `sounds/credit_kimi.wav` |
| Jev | ジェブ | `sounds/credit_jev.wav` |

読みの表は `core/credit.READINGS`。録音は `scripts/gen_credit_voices.py` が、いまの声（Style-Bert-VITS2・`.env` の
`SBV2_*`）で前もって作る。合成サーバーが止まっていれば起こし、作り終えたら止める。読みや声を変えたら、回し直す。

## 6. 確かめること

机上はテストで確かめた。実機では次を見る。

- **録音の聞こえ方**：読み（特に「ジェブ」「チャットジーピーティー」）。
- **担い手ごとの返り方**：Gemini 以外は文書の上の推測なので、実際に切れたときのログで見直す。実機で残高を切らすのは
  難しいので、偽の失敗を差し込んで鳴るかを確かめる。

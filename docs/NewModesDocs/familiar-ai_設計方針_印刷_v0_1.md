## 3. 仕組み（段 1、`io/printer.py`）

- **ひな形**（`page_html`）：題（20pt）、日付（10pt）、本文（12pt）。本文の「- 」「・」「* 」で始まる行は箇条書き（外すのは頭の印 1 つだけ）、空行で区切る。
  言葉は印として読ませない（`<` などはそのまま字として出す）。
- **PDF**（`render_pdf`）：Qt の `QTextDocument` を `QPdfWriter` へ書き出す。A4 縦、余白 20 mm。紙の書ける範囲を「点」で渡す
  （書き出しのピクセルで渡すと、12pt が点ほどの大きさになった、2026-11-22 に描いて確かめた）。Qt のアプリが動いている
  ことが要る（画面のパジュでは動いている）。アプリが無いとき、書き終えたファイルが PDF でないときは `PrintError`。
- **刷る**（`send_to_printer`）：`lp -d <プリンタ> -o print-color-mode=monochrome -o sides=one-sided -o media=A4 <PDF>`。
  `LC_ALL=C` で呼び、受付番号（`request id is …`）を返す（この機体の言語では「リクエスト ID は …」と言うため）。番号を読めなければ
  警告を残す。`lp` が受け付けなければ、わけを持った `PrintError`。`lp` は 20 秒まで待つ（受け付ける
  だけで、紙が出るのは待たない）。待つあいだ止まるので、非同期の口からは `asyncio.to_thread` で呼ぶ。

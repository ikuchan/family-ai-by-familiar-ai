# familiar-ai 設計方針：記憶をモデルに入れる（MeMo の検討）

**検討の段である。まだ何も作っていない**（記-af、2026-11-23 新設、本人「検討を課題に立てて始めて」）。論文 MeMo（記憶を小さなモデルの
重みに入れる）を、パジュの記憶とどう両立させるかを決める。本人が先に考えたいと言ったのは 2 つ：**速度**と、**いまの記憶の構造との
両立**（2026-11-23）。検討の元は ObsidianMemo のセッション（cl2）からの引き継ぎで、ここではパジュの側の事実で確かめ直した。

## 1. 論文の要点（MeMo: Memory as a Model、arXiv:2605.15156、2026-05）

- 文書を大きいモデルで大量の一問一答に変え、記憶用のモデルを丸ごと追加学習する。主LLM は凍結し、記憶用のモデルに文章で質問する。
  聞き方は 3 段（小さな問いに分ける → 対象を 1 つに絞る → 裏付けを取ってまとめる）で、最大 16 回聞く。
- 物語や多段の問い（NarrativeQA、MuSiQue）でグラフ RAG を上回り、無関係な文書を混ぜても精度がほぼ落ちない。
- **聞き手で精度が大きく変わる**：同じ記憶用のモデルでも、上限との差は聞き手が弱いと 24.5 点、強いと 6.8 点（NarrativeQA）。情報は重みに
  残っていて、足りないのは聞き出す力。
- **後から知識を足すのが弱い**：別々に学習した重みを合わせる（TIES）と大きく落ちる。合わせない足し方（全部学習し直す、並べる、差分だけ
  学習）は論文では試していない。
- 記憶用のモデルが 1.5B でも、聞き手が強ければそこそこ出る（14B の 53.6 に対し 47.4）。
- 測っていないもの：記憶が大きくなったときの落ち方、数字を一字一句保てるか、幻覚の率、答えるのにかかる実時間。

### 学習の材料と道具（2026-11-23 に読むだけで数えた）

**材料**は、夜の REST が作ったものが溜まっている。

| 材料 | 件数 | 形 |
|---|---|---|
| 事実の鍵の文（`obs_fact_keys`） | 事実 6,059 件（主語の側と答えの側で 12,118 文・平均 23 字）、元の記録 2,229 件 | 主語、関係、答え。元は最終版 682 件、求め 505 件、人物 358 件、記憶 306 件 ほか |
| 畳んだ自己エピソード（向き 記憶） | 333 件（平均 357 字） | 1 日を一人称でまとめたもの |
| 内省 | 198 件（平均 185 字） | |
| 人ごとの月のまとめ、まとめ | 19 件、18 件 | 人との関係と「いつもの」 |

事実の鍵の文は、そのまま一問一答に組みかえられる形をしている（主語と関係が問い、答えが答え）。6,000 件ほどは論文の規模（文書ごとに大量の
一問一答）より小さいので、足りるかは小さく学習して確かめるしかない。

**道具**は、半分だけ入っている。torch 2.10（CUDA 12.8）と transformers 5.2 はもう入っている。小さいモデルを 8 GB の空きで追加学習するには、
重みを丸ごと学習するのではなく差分だけを学習する道具（peft など）が要る（1.5B を丸ごと学習すると、最適化の状態だけで 12 GB を越える）。
これは入っていない。

## 3. 両立の考え方（案、未決）

- **役割を分ける（おすすめの向き）**：いまの記憶は「一緒に過ごした出来事」（いつ、誰と、気分、薄れる）、記憶用のモデルは「固まった知識」
  （関係、事実、薄れない）。海馬と大脳皮質の分担に近い。
- **つなぎ目は夜の REST**：REST が残したもの（畳んだ自己エピソード、まとめ、**事実の鍵の文**）で毎晩まとめて学習し直す。重みを合わせない
  ので、論文の弱点（後から足すと落ちる）を避けられる。`rest_facts` がもう作っている「問いに近い鍵の文」は、MeMo の一問一答の材料に
  ほぼそのまま使える〔推測〕。
- **ティア**：家族の記憶用モデルと個人（Vault 全体）の記憶用モデルを分け、いまの話者ゲート（道具名の接尾辞）に乗せる。1 つの重みで分け
  られるかは未検証。
- **時間、気分、顔ぶれ**：一問一答に日付、気分、顔ぶれを書き込めば重みに入るかもしれない（書く版と書かない版を比べる、未検証）。

## 4. 速度の考え方（案、未測定）

- 時間を食うのは、聞き手（主LLM）の往復の回数で、記憶用のモデル本体ではない〔推測〕。
- 聞き方の候補：①1 回だけ聞く（速い道）②同じ段の問いをまとめて投げて 3 往復 ③夜に翌日出そうな話題を先に聞いておき、昼は即出す
  （外れたら①で補う）。
- 毎回の自動の想起（W）に混ぜるかは、1 回の答えの実測の秒数で決める。

## 5. 次の手（順に、本人の判断が要るところに印）

1. **測る準備（承認なしで進める）**：`rest_facts` の鍵の文と `rest_fold` の産物が、一問一答の材料として何件、どんな形で溜まっているかを
   読むだけで数える。家族の固有名詞は数と形だけで扱い、外へ出さない。
2. **【承認が要る】学習と推論の道具を入れる**：差分だけを学習する道具（peft）と、記憶用のモデルの重み（1.5B で約 3 GB）が要る。
   transformers と torch はもう入っている。依存の追加なので本人に聞く。
3. **【承認が要る】GPU の取り合い**：学習は夜に、パジュを止めずに 8 GB の空きで回せるかを測る。パジュを止めて回すなら、その時間を本人と決める。
4. **測る**：小さく 1 回学習し、①記憶用のモデル 1 回の答えの秒数 ②3 段の聞き方の合計の秒数、を測る。聞き手は haiku と opus の両方で。
5. 測った数で、役割の分け方、聞き方、W に混ぜるかを本人と決める。

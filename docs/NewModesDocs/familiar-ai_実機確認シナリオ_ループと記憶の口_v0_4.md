# familiar-ai 実機確認シナリオ：ループと記憶の口（v0.4）

## 目的

`課題8` §7 の**束 C（次の実機セッションで確かめる・18 行）**を、1 回のセッションで**上から順に**消化する手順書。
束 C は「起動 → 会話 → 無人」の順に並べてあるので、この資料も同じ順に並べる。各段に、**打つ操作**・**成り立つ場合に
見えるもの**（画面・ログの行）・**間違っていれば見えるはずのもの**を対で記す。判定は事実だけで下す。

対象は 2026-09-11 から 09-18 までに入れた変更（環-f 以降・情-h・知-m・知-n・知-o・知-p・知-q・情-i・情-j・記-a の 4 層）。
どれも全体テスト（3,017 件・緑）は通っているが、**テストが見ているのは呼び出しの形**であって、首が回るか・音が鳴るか・
聞かないか・返事が返るかではない。

## 2. 手順

見えるものの「ログ」は `~/.cache/familiar-ai/app.log` の行（`--debug` で出るものは【D】と記す）。

### 起動（C-1・C-9）

| 打つ | 成り立つ場合に見える | 間違っていれば見える |
|---|---|---|
| 起動して 2 分待つ | `Microphone capture … gain=2.5`。温め（TTS・Whisper・YOLO）が**起動時に 1 回ずつ** | 発話のたびに温めのログが出る（環-k の再発） |
| 「**パジュ、こんにちは**」 | 数秒で返事（`event-loop 終了: … 結末=発話`）。`_take_trigger` 経由で待たされない | 88 秒待つ（環-m の再発・12:40 の形） |
| 「**今日は何曜日？**」（続きの発話） | `rest_logs/measure.log` に `続き先 結末=続き／途切れ／未判定` が 1 発話 1 行 | 行が無い（記-i の配線） |

### 会話 1（C-11・C-10）

| 打つ | 成り立つ | 間違い |
|---|---|---|
| 「**パジュ、何が見える？**」 | `調停=light` か `action=see` → 返事に写真の中身・40 字前後（effort=low） | 見ずに答える・160 字超 |
| 「**よく考えて答えて。金木犀はいつ咲く？**」 | `主LLM … effort=high`・調べた後 160〜240 字 | low のまま |
| ログを見る【D】 | `OIF write／recall／link` が出る。記憶へ直の `save_async` のログが無い | 直の呼び出しのログがある（環-e-い） |

### 会話 2（C-2・C-5e）

| 打つ | 成り立つ | 間違い |
|---|---|---|
| 「**パジュ、窓のほう見て**」 | `調停=action … action=look`・`調べもの look … 窓を見に行く` → 首が回り、**向き終わってから**撮った写真で答える（`窓で見えたもの`） | 途中の位置で撮る・帰りの調停がもう一度 `look` を選ぶ |
| 「**右向いて**」 | 右（pan 負）へ。`右の…のほうを向いた` | 左へ向く（`RIGHT_IS_POSITIVE_PAN` の逆） |
| 情動の求めのとき【D】 | `[いま]` に `見ていない順：テレビ 未・窓 12 分・出入口 0 分`。調停が `look` で pose を書かなければ `look の行き先を機械で決めた：…` | `見ていない順` が無い・同じ定点を見続ける |

### 会話 3（C-5b・C-4）

| 打つ | 成り立つ | 間違い |
|---|---|---|
| 「**パジュ、静かにして**」（名前が化けてもよい） | `書き起こした` の本文に「はじゅ／パチュ」でも、黙る（`名前で呼ばれていないので受けない` が**出ない**）。`hotwords` で「パジュ」と書かれれば上出来 | `黙っているよう読めたが、名前で呼ばれていないので受けない`（情-i の再発） |
| 黙っている間に別の人（か `/speaker たいき` に切り替えて）が「**パジュ、今日の天気は？**」 | `黙っているので聞くだけ：会話入力 …`。返事なし | 返事が出る（案イの復活） |
| 本人（`/speaker パパ` に戻して）「**もう話していいよ**」 | 1 つの求めが立ち【D】W に `黙っていたあいだ（HH:MM〜HH:MM）に届いたもの——聞いたこと N 件…`。1 回でまとめて答える | 求めが 2 つ以上立つ・列挙が無い |
| 「**待てぃ**」（名前なし） | 黙らない（名前が無い） | 60 分黙る |
| 喋っている最中に「静かにして」 | `gated transcript (tts_active)` で捨てられる——**これは既知（案エ・未着手）**。記録だけ | — |

### 会話 4（C-5f・C-3・C-5d）

| 打つ | 成り立つ | 間違い |
|---|---|---|
| 設定画面「声」タブ → 「タイマー」欄の 3 チェックを確かめる（全部 on）→ 保存 | 吹き出しに `.env` の読み直し。**再起動なし** | 再起動を求められる・次の確認文が変わらない |
| 「**パジュ、3 分測って**」 | まず「3 分のタイマーね。その間は黙って聞かないよ、いい？」（`TIMER_CONFIRM`）。**まだ掛かっていない** | いきなり掛かる |
| 「**いいよ**」 | `タイマーを掛けた id=1 …`。黙る（`TIMER_SILENCE`）。状態行「🔇 聞いていない（タイマー「…」が鳴るまで）」。`[タイマー]` の枠に「聞いていない（… 止めて・一時停止・再開の言葉だけ届く）」【D】 | 🔇 が出ない・枠に無い |
| 「**こんにちは**」（タイマー中） | `聞いていない（タイマー「…」）：'こんにちは'`。返事なし・O にも残らない | 返事が出る・`ので聞くだけ` に落ちる（沈黙の器に入ってしまう） |
| 「**一時停止**」 | 通る → `タイマーを一時停止 id=1`・`止めておく：id=1 「…」 残り m:ss`。**聞く状態に戻る**（🔇 が消える・「こんにちは」に返事する） | 捨てられる・残りが減り続ける |
| 「**再開**」 | `タイマーを再開 id=1`。残りが止めた時点から続く。🔇 に戻る | `due` が伸びていない（早く鳴る） |
| 「**もう 1 本、2 分測って**」 | 「いま「…」（id=1 残り m:ss）が動いている。止めるか、鳴るのを待ってから」。掛からない | 2 本目が掛かる |
| 鳴る | `タイマーが鳴った id=1`・`DIF タイマーの音を鳴らす（30 秒・倍率 1.50）`・音が YVC-300 から出る。沈黙が解ける（`[届いた知らせ]` の求め）。**声で「タイマーです」とは言わない**（調停が黙るのが基本） | 音が出ない（`DIF タイマーの音が出なかった`）・鳴った知らせでタイマーを掛け直す |
| 鳴っている間に「**止めて**」 | `DIF タイマーの音を止めた`。音をマイクが拾った書き起こしは `no_speech_prob` で落ちる（`音声でないとみなして捨てた`） | 音で求めが立つ（→ `STT_NO_SPEECH_MAX` を見直す）・「止めて」が届かない |
| 設定画面で「聞かない」を off → 保存 → 「1 分測って」→「いい」 | 確認文が「その間は黙っているよ、いい？」に変わり、タイマー中も「こんにちは」に返事しない（黙る）が **🔇 は出ない**（聞いてはいる） | 文が変わらない（保存で効いていない） |
| `/mic on`（別のタイマー中） | `タイマー中でも聞く：1`・🔇 が消える | — |

## 4. 中止条件

- **起動の「こんにちは」に返事が来なければ、そこで止める。** 残りは測れない。
- **マイグレーション（066・067）が例外で止まったら、そこで止める。** 本番への書き込みなので、原因の調査だけ。
- **例外が出たら、その場でログを保存する。** 変更は 15 あり、どれが原因かはログでしか分からない。
- **首が回らない・音が出ない・聞かないが効かないは、機器側の可能性が先。** `tapo_ptz_check.py`・`_play_via_sounddevice`・`mic_gate` の挿し込み（GUI が agent を持ったあとに `_attach_mic_gate`）を疑う。

- 各行は `課題8` §7 の状態欄に「確認済み（日時・見えたもの）」で書き戻す。破綻は行を残し、原因の切り分け（値は課題5・結線はコード）へ。
- 会話 2 の首が回れば **知-c の土台**（E-1 の前提）が実機了。E-1 そのもの（無人で自発の見回りが定点を巡る）は無人の段で `look の行き先を機械で決めた` が出るかで見る。

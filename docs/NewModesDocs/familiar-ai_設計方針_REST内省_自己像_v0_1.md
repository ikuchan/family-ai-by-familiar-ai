# familiar-ai 設計方針：REST 内省・層 2「自己像」（v0.1）

自己像は、REST 内省の 4 層（出来事 → 自己像 → 設定値 → 能力・`用語一覧` v0.70）の第 2 層で、
**いま自分が何を望み、何を気にかけ、何を大事にしているか**を持つ。出来事（層 1）と能力（層 4）の
あいだに立ち、**抽象・字数に厳密な上限・大きくしない**。REST 内省が層 1 の畳み込みの結果から
抽象を取り出して更新する（動詞は「抽象化する」）。

## 1. 目的

会話と自発の行動に「いまの自分の関心」を効かせる。出来事は具体で増え続け、能力は道具に根ざして
動かない。そのあいだに、日々の出来事から立ち上がる短い自己像を置くことで、主LLM は「昨日こうきと
サッカーの話をしたから今日も気にかけている」といった連続性を持てる。**記憶ではない**——W の枠には
入らず、システム文の安定部に載る。

## 2. 外形（2026-09-14 決定・4 層共通）

| 層 | 現在値 | 既定値（GitHub） |
|---|---|---|
| 1 出来事 | DB | — |
| **2 自己像** | **DB：`agent_state` の鍵 `self_image`** | **種**：repo の `defaults/self_image.yaml`（空でもよい） |
| 3 設定値 | DB：`agent_state.config_overrides` | `config.py` の既定値 |
| 4 能力 | DB：再生成した一覧と要約 | `capabilities.yaml`（実行時に書き換えない） |

- **状態はすべて DB、ファイルは既定と人の入力だけ**。`CLAUDE.md` の「保存は PostgreSQL のみ」はそのまま。
- `.env` は機密と機体固有のもの（鍵・URL・機器 id・モデル・TTS の担い手）だけ。4 層の値は `.env` に置かず、
  あっても読まない。
- `ME.md`・`FAMILY.md` は人が書く定義（入力）。機密扱い・Drive 同期のまま。

## 3. 中身

| 欄 | 何を書くか | 行数 × 1 行の字数〔仮〕 |
|---|---|---|
| 望み | いま自分がしたいこと（人に向くもの・自分に向くもの） | 3 × 40 |
| 気がかり | 気になっている人・こと（未解決の約束・心配・楽しみ） | 3 × 40 |
| 価値 | 大事にしていること（振る舞いの基準になるもの） | 5 × 30 |

- 合計上限 **390 字**〔仮〕。上限は切るのではなく **LLM に収めさせる**（収まらなければその更新は捨てて前の値を残す）。
- 各行は自然文。数値・内部指標・id を書かない（読み手は主LLM と人）。
- **各行は出典を持つ**：材料にした自己エピソード（層 1 の産物）の id を、行の外側（DB の JSON）に持つ。
  材料に無いことは書けない。

DB の形（`agent_state.self_image`）：

```json
{"望み": [{"text": "…", "since": "2026-09-14", "sources": ["<自己エピソード id>"]}],
 "気がかり": [...], "価値": [...], "updated_at": "…"}
```

`since` は行が入った日。**古さの印**として主LLM に渡す（「先週から気にかけている」）。

## 4. 読み手

- システム文の安定部に **`[自分のいま]`** として、`[あなたは誰か]`（層 4 の要約）の直後に載せる。
  1 日 1 回しか変わらないのでキャッシュを壊さない。
- 調停（軽量LLM）にも同じものを渡す。記憶ではないので、窓の差（記-h）は無い。
- 主LLM への指示は「いまの自分の関心として読む。口に出す義務はない」。自発の求め（情動）では、何を
  見に行くか・誰に声を掛けるかの材料になる。

## 5. 更新（REST 内省・層 2 の仕事）

1. 材料：層 1 がその晩に作った **自己エピソード**と**関係のまとめ**、いまの自己像。
2. LLM（フル）が上限内で書き直す。出力は 3 欄の行と、行ごとの出典 id。
3. 機械の検査：字数・行数・出典が材料にあるか。通らなければ**更新しない**（前の値を残し、ログに理由）。
4. **1 パスで変えてよい行数に上限**〔仮 3 行〕。一晩で人格が入れ替わらない。
5. 履歴は出来事の層に：更新のたびに `direction='内省'` の記録を 1 件書く（「望み『…』を『…』に変えた・出典 …」）。
   `agent_state` は現在値だけを持つ。
6. 初期値：DB に無ければ `defaults/self_image.yaml` の種を入れる。種は空でもよい（最初の内省で埋まる）。

## 6. 旧機構の撤去（環-d へ）

`agent_state.desires`（`DesireSystem` の数値の重み・2026-07-26 から更新なし）、`agent_state.concerns`
（`ConcernEngine`）、`behavior_policies`（`_maybe_adapt_values`）は、いずれも**イベント駆動ループの
プロンプトに届いていない**（読み手が無い）。自己像がその役目を持つ。撤去は環-d の一部として行う。

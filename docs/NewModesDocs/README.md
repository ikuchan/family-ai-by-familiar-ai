# familiar-ai 設計ドキュメント索引（v3.1）

`docs/NewModesDocs/` は、familiar-ai の設計と計画の正本を置く場所である。実装に手を付ける前に、触る領域の正本をここで確かめる。

各資料は版番号で管理し、**ファイル名の版＝タイトルの版**で揃える。本文（最新の状態）が先、`## 更新履歴` は末尾に置く。資料を書く・直すときは `.claude/rules/文章規範.md` に従う。

## どこから読むか

| 知りたいこと | 見る資料 |
|---|---|
| いま何をしていて、次に何をするか | **直近の進め方と進捗** → **課題8 段取り設計 §7** |
| 全体の構造・コンポーネントの境界 | **設計図（Mermaid）** |
| 用語や略語の意味 | **用語・略語一覧** |
| パラメータの値と、その根拠 | **課題5 パラメータ仮案** → **計測・設定値 根拠台帳** |
| 感情・欲求がどう回るか | **感情ループ全体像** |
| いま作っているループの中身 | **イベント駆動ループ** → **I 内部設計根拠** |

## 扱いの約束

- **正本を先に読む**。関連コードを触る前に、その領域の資料を読む。新しい設計・計画は必ずここへ書く（版番号つき）。
- **`@import` で全部を取り込まない**。毎セッション読み込むには重い。必要なものを都度開く。
- **実装済みのことだけを書く**とは限らない。設計資料には未実装の決定が含まれる（`CLAUDE.md` とコードは実装済みのことだけを書く、という規則とは扱いが違う）。どこまで実装したかは、設計図の「store と I/F」台帳と、各実装記録の資料が持つ。

## 1. 困っていること

「印刷して」と頼まれても刷れない。プリンタは CUPS に登録してあり（`Brother_DCP_J552N`。IPP のドライバ不要の登録で、既定の紙は
A4）、待機している。2026-10-24 に別のセッションで試したとき、白黒の指定 `ColorModel=Gray` が効かずカラーで出た。紙が出終わっても
`lpstat -o` にジョブが残り、刷り終えたかを確かめられなかった。

## 3. 仕組み（段 1、`io/printer.py`）

- **ひな形**（`page_html`）：題（20pt）、日付（10pt）、本文（12pt）。本文の「- 」「・」「* 」で始まる行は箇条書き（外すのは頭の印 1 つだけ）、空行で区切る。
  言葉は印として読ませない（`<` などはそのまま字として出す）。
- **PDF**（`render_pdf`）：Qt の `QTextDocument` を `QPdfWriter` へ書き出す。A4 縦、余白 20 mm。紙の書ける範囲を「点」で渡す
  （書き出しのピクセルで渡すと、12pt が点ほどの大きさになった、2026-11-22 に描いて確かめた）。Qt のアプリが動いている
  ことが要る（画面のパジュでは動いている）。アプリが無いとき、書き終えたファイルが PDF でないときは `PrintError`。
- **刷る**（`send_to_printer`）：`lp -d <プリンタ> -o print-color-mode=monochrome -o sides=one-sided -o media=A4 <PDF>`。
  `LC_ALL=C` で呼び、受付番号（`request id is …`）を返す（この機体の言語では「リクエスト ID は …」と言うため）。番号を読めなければ
  警告を残す。`lp` が受け付けなければ、わけを持った `PrintError`。`lp` は 20 秒まで待つ（受け付ける
  だけで、紙が出るのは待たない）。待つあいだ止まるので、非同期の口からは `asyncio.to_thread` で呼ぶ。

## 4. 頼まれて刷る道具（段 2、`tools/print_tool.py`）

- **道具**：`print_document`（題 `title`、日付 `date`、本文 `body`。日付が無ければ今日）。主LLM の道具の並び（`_FULL_ACTIONS`）
  にだけ置き、調停の候補（`_extra_actions`）には置かない。PDF を作れない起動（Qt のアプリが無い）では道具を渡さない
  （家族に聞いてから断らない）。「印刷して」は、調停から主LLM へ渡り、主LLM が直前の会話の中身を
  まとめて呼ぶ。
- **確かめ**：確かめる前の呼び出しは、確認待ち（`confirm_state.PendingConfirm`）を置き、「まだ刷っていない」とだけ返す。問い
  「『〇〇』を N 枚刷るね。いい？」は機械が読み上げる（タイマーと同じ）。N は、聞く前に組んで数えた枚数（「1 枚」と言って
  2 枚出さない）。「いい」なら機械が預かった入力で呼び直し
  （`agent.resolve_confirm`、`confirmed=True`）、「やめて」なら「やめた：『〇〇』は刷らない」。答えを待つあいだの促しは
  「いま印刷するか確かめているところだよ」。待つあいだ、もう一度刷る呼び出しは機械が落とす。
- **刷る**：PDF は `~/.cache/familiar-ai/print/` に書き、`lp` に渡したら消す（会話の中身をファイルに残さない）。`lp` はスレッドで待つ。プリンタの名前は
  `AgentConfig.printer_name`（`Brother_DCP_J552N`）。刷れなければ（プリンタが受け付けない、フォルダを作れない、Qt が無い）失敗として返り、調停が軽く伝える。

## 5. 本物の紙で刷ってみた（段 3・2026-11-22・本人の承認）

家族の情報を含まない試しの文（題「パジュの試し刷り」）を `render_pdf` と `send_to_printer` で 1 枚刷った。受付番号
（`Brother_DCP_J552N-8`）は `LC_ALL=C` で読めた。頼んでから約 30 秒で印刷待ちの一覧（`lpstat -o`）からジョブが消え、完了の一覧に
入った（2026-10-24 の「刷り終えてもジョブが残る」は起きなかった）。本人が紙を見て、ちゃんと出ていた（2026-11-23）。`print-color-mode=monochrome` は効いている。

## 6. 確かめていないこと

- 「印刷して」が実際に主LLM へ渡り、主LLM が道具を呼ぶか（家で頼んでみる）。

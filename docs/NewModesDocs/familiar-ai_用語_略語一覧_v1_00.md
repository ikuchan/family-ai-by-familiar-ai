## ループの語（環-g・2026-09-08 に1つへ決めた）

`loop/event_loop.py` で同じものに複数の名前が付いていたので、次のとおり決める。設計方針は
`設計方針_ループの語を束ねる` にある。**実装はこれから。**

| 語 | 意味 | この意味で使わない語 |
|---|---|---|
| **求め** | 人の発話・情動・機器のどれかで始まり、発話で閉じるまでの1単位。反復は複数ありうる。上限（既定5）が縛るのは**続けて調べる回数**だけで、求め全体の長さではない | 「連鎖」を求めの意味で使わない |
| **反復** | 求めの中の1回。**1反復＝1出力**（発話かツール投げのどちらか1つ）。2種類ある——**決める反復**（軽量LLM が司り、調べものか主LLM を投げる）と**出す反復**（主LLM の返りをそのまま実行する）。数えるのは決める反復だけで、**主LLM の返りで 0 に戻る**（環-h） | 「連鎖長」 |
| **きっかけの種別** | IIF の待ち行列が運ぶ `Trigger` の種類。**6つ**——`完了`（調べものの結果が届いた）・`進捗`（まだかかっている。結果ではないので飛行中の数も版も触らず、短い一言のためだけに反復を起こす）・**`決定`**（主LLM の返り。`TurnResult` と、投げたときに見ていた W を `Decision` として運ぶ）・`情動`（drive が発火した）・`機器`（人が出入りした）。**6つ**目が `会話入力`（人が話しかけた。`future` で呼び手が待つ）。**`会話入力`・`機器`・`情動` は新しい求めを始める**ので、調査中は保留箱で待たせる（ただし `会話入力` は待たせない——言い直しは前の調査を打ち切る側）。同時に届いた中から1つ選ぶ順は **会話入力 ＞ 機器 ＞ 情動** | 「決定」を調停（軽量LLM）の選択の意味で使わない——そちらは `branch` である |
| **考えた回数** | この求めで主LLM を呼んだ回数。反復の数は主LLM の返りで 0 へ戻るので、**求めの長さを表すのはこちら**である。`_lookups` の `action="主LLM"` から導き（別の変数で数えない）、主LLM のプロンプト・調停・ログの三箇所へ同じ値を渡す | 「反復数」を求めの長さの意味で使わない |
| **記録の鎖** | O の supersede の連なり。新しい記録が直前の生きた記録を畳むので、生き残るのは先頭1件 | 「鎖」を単独で使わない |
| **版** | 求めの状態を書いた O の記録。新しい版が直前の版を畳む | 「意図O」——実際に O へ書かれるのは版である |
| **調べもの** | 1件の外部呼び出し（`see`／`look`／`recall`／`search_deferred`／`fetch_deferred`） | 「調査」「検索」を混ぜて使わない |
| **やりとり** | 1ターンの記録（起点・版・見た・つなぎ・答え・要約）を順序つきで束ねた関係 | — |
| **起点** | やりとりの中で、そのターンを始めた記録につける役割 | 求めや記録の鎖の先頭を「起点」と呼ばない |
| **独白** | 主LLM が `say` を呼ばず地の文だけを返した反復の記録、または**相手が居ないので言わなかった独り言**（情-c・2026-09-13。積まずに思ったことだけ残す）。**画面には出たが声にはなっていない**（規則 `voice-only-from-say`）。`direction="独白"`・役割 `独白` で、文言は `考えたが言わなかった：…`。やりとりの項にはならないが（`recent_exchanges` が引く役割に無い）、**拡散想起の母集合には入る**（`HIDDEN_ROLES` に入れないので想起からも消えない） | 「発話」と呼ばない——相手は聞いていない |
| **ひとりの回数**（solitude） | 人と会話しないかぎり増える軸ごとの整数 $n_i$（SEEKING・SAFETY・BOND）。欲求の蓄積に $2^{-n_i}$ を掛け、発火間隔を倍々に伸ばす。発火で +1、人の発話で 0（`core/solitude.py`・情-d） | 「不応期」と混ぜない（不応期は置かない） |
| **返事の予算**（reply budget） | 求めごとに機械で決める返事の長さ（目標字数・上限字数）と、そこから固定する API の出力上限 `max_tokens`。主LLM には `[返事] 目標 40 字・80 字以内` の 1 行で渡す（`loop/reply_budget.py`・出-k-ろ・値は 課題5 G 章） | 「文字数制限」「トークン制限」を別々に言わない |

|---|---|
| 記 | 記憶と内省 |
| 情 | 感情と自発 |

| 環 | ループの構造と撤去 |
| 出 | 出力と基盤 |

**「課題 N」（設計図の残課題）とは別の体系である。** あちらは設計文書全体から参照される固定 ID で、完了しても詰めない。旧番号（`#8`・`#11` など）との対応表は `課題8 §7` にある。

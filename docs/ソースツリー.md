# familiar-ai ソースツリー

`src/familiar_agent/` のモジュール構成。CLAUDE.md から分離した参照用。最新はリポジトリの
`src/familiar_agent/` を直接見る。

```text
src/familiar_agent/
├── agent.py                  # 身体を持つメインのターンループ
├── appraisal.py              # 低次元の感情更新
├── attention_schema.py       # 直近の焦点・注意状態
├── backend.py                # LLM バックエンドのプロトコルと実装
├── bootstrap.py              # 起動・セットアップ・設定状態の処理
├── camera_discovery.py       # Zeroconf とネットワークカメラの発見
├── capability_state.py       # capability manifest 読み込みと自己理解の保存
├── concern_engine.py         # 未解決の関心事
├── config.py                 # 実行時の設定オブジェクト
├── db.py                     # PostgreSQL シングルトン（get_db()）
├── db_migrations.py          # マイグレーション実行（apply_migrations）
├── default_mode.py           # アイドル既定モードの記憶処理（DMN）
├── desires.py                # 自律欲求と欲求選択
├── diagnostics.py            # GUI 診断と接続テスト
├── event_bus.py              # 内部イベントバス
├── exploration.py            # 空間探索の状態
├── gui.py                    # PySide6 GUI
├── heartbeat.py              # 継続・実行状態のロジック
├── interoception.py          # 内受容の供給と意味的圧
├── intervention_policy.py    # 自律介入のゲート
├── main.py                   # CLI エントリ・モード選択
├── mcp_client.py             # Model Context Protocol クライアント
├── memory_worker.py          # 非同期の記憶ジョブワーカー
├── mental_state.py           # メンタル状態バスと PostgreSQL スナップショット
├── meta_monitor.py           # メタ認知ログと応答ゲート
├── person_memory_manager.py  # 多人数の同定と記憶ルーティング
├── prediction.py             # 予測誤差・行為主体誤差
├── realtime_stt_session.py   # ストリーミング STT セッション管理
├── reflect.py                # 自己内省と価値適応
├── relationship.py           # 長期の関係状態
├── routines.py               # 静穏時間・ルーチン設定の補助
├── scene.py                  # シーン実体の追跡
├── self_narrative.py         # セッションをまたぐ自伝的物語
├── self_state.py             # 永続する潜在的な身体状態
├── settings_schema.py        # 設定スキーマと検証
├── setup.py                  # セットアップ、環境移行、検証
├── social_policy.py          # 発話行為分類と応答モード
├── sqlite_migrations.py      # 旧 SQLite マイグレーション（未使用）
├── tape.py                   # 行動計画（TAPE 機構）
├── tui.py                    # テキスト UI
├── voice_guard.py            # TTS/STT ループ防止
├── workspace.py              # コアリション競合とブロードキャスト
├── _i18n.py                  # 国際化補助
├── _ui_helpers.py            # 共有 UI ユーティリティ
├── tools/
│   ├── camera.py
│   ├── coding.py
│   ├── deferred_fetch.py     # 撃ちっぱなし URL 取得、結果は次ターンに注入
│   ├── deferred_search.py    # 撃ちっぱなし web 検索、結果は次ターンに注入
│   ├── memory.py
│   ├── mic.py
│   ├── mobility.py
│   ├── person.py
│   ├── realtime_stt.py
│   ├── stt.py
│   ├── tom.py
│   └── tts.py
└── recognition/
    ├── face.py               # 顔認識
    ├── presence_watcher.py   # 背景でのカメラ在席ポーリング
    └── voice.py              # 声紋の話者同定（配線は保留・issue #4）
```

## 6. 所見と解釈

### 6.1 bge-m3 自体の識別力は高い

最近傍 top-5 分布（p50=0.59）と無関係分布（p50=−0.02）の差は **+0.61** と非常に大きい。  
bge-m3 は意味的に類似したコンテンツを高コサインでまとめることができている。  
e5-small の課題だった「段階的関連を分けきれない」は、**bge-m3の埋め込み空間自体では解消**されている可能性が高い。

### 6.2 問題は関連プロキシの品質

擬似セッション内ペアの p25 が −0.05（無関係 p50 の −0.02 とほぼ同値）であることは、**擬似セッションが意味的関連の代理として機能していない**ことを示す。

なぜか：
- 1セッションの中央値が4件しかない → 多くのセッションが2〜3件の短いやり取り（時間近接しているが意味が同一とは限らない）
- 長大セッション（平均21件）は多様なトピックを横断し、セッション内の非関連ペアも大量に混入する
- セッション内の隣接発話「おはよう」→「天気は？」→「宿題します」は時間的に近いが意味的には無関係

つまり **P(関連>無関係) ≈ 0.63 ≈ chance + α** という結果は、プロキシの問題であり、bge-m3 の性能の問題ではない。

### 6.3 e5-small 前回値との比較の解釈

前回の c_lo=0.354、c_hi=0.555 は「意味ラベル（同一日・10分近接）ペア」と生コサインによるものであり、計測方法が異なる（指示書 v0.3 方式）。今回の擬似セッション方式（v0.5）とは直接比較できない。

## 7. 結論と推奨次ステップ

### 運用可能な c_lo/c_hi が出なかった理由のまとめ

1. **擬似セッションプロキシの不適合**: 時間近接 ≠ 意味的関連（このデータセットでは特に顕著）
2. **perspective vec がゼロ**: 全視点が同一のため「視点ごとの差分」を持ち込めていない

### 推奨アクション

| 優先度 | アクション | 理由 |
|---|---|---|
| 高 | **関連ペア定義の再設計**: セッション内ではなく「意味的近傍 top-k を真の関連」として使う | nn_top5 分布（p50=0.59）は実際の意味近傍を正しく捉えている |
| 高 | **perspective vec の再蓄積を待つ**: 数週間の運用後に再計測 | 現在ゼロのため視点差分なし |
| 中 | **セッション長のフィルタ**: 長大セッション（>50件等）を除外して再測定 | 長大セッションが関連分布を汚染している可能性 |
| 低 | **計測指示書 v0.6 策定**: 意味近傍ベースの関連定義に切り替え | より信頼できる c_lo/c_hi 値が得られる |

### 暫定 c_lo/c_hi 運用案

現時点では正統な c_lo/c_hi が確定できない。bge-m3 の無関係分布から推測すると：

- 無関係 p95 = **0.25** をそのまま c_lo の保守的下限として使用
- c_hi は nn_top5 p25 = **0.50** を暫定上限として参照
- この場合の窓幅 = 0.25（e5-small の 0.20 より広い可能性）

ただしこれは意味近傍ベースの暫定値であり、正式な計測ではない。
